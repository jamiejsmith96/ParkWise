```xml

  * All blog posts (upcoming)
  * All location pages (upcoming)

**3. robots.txt** ✅ Implementing Now
```
- Allow search engine crawling
- Disallow admin pages
- Point to sitemap

**4. Structured Data (Schema.org JSON-LD)** ✅ Implementing Now
```json

- WebSite schema (site-wide search)
- BreadcrumbList (navigation)
- LocalBusiness schema (for each park)
- Product schema (caravans)
- AggregateRating schema (park reviews)
- FAQPage schema (guides)
- HowTo schema (calculators)
```
